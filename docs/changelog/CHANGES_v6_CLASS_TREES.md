# v6 — Class-Exclusive Ascension Trees

## What changed

The previous Ascension Grid mixed nine elemental spokes and four class lanes around the same root socket. At runtime that put multiple gateways, labels and the level badge in the same central area, which is why the screenshot looked like a pile of overlapping circles.

### New tree structure

Each playable class now has its own constellation:

- **VIPER — Venom Architect:** Toxic Dominion / Widow's Silence / Plague Heart
- **PYTHON — Colossal Engine:** Titan Body / Iron Citadel / Iron Constrictor
- **COBRA — Venom Artillery:** Hydra Barrage / Serpent Cannon / Prismatic Cobra
- **MAMBA — Thunder Assassin:** Lightning Executioner / Voidstep Predator / Tempo Reaper

Every class has 26 visible class-specific sockets, three major branches, side clusters, and four class-specific elemental mastery sockets.

### Keystone choices

The three keystones of a class share a mutually-exclusive doctrine group. Taking one blocks the other two. This makes the build choice change the class skill's behavior instead of turning every path into the same +damage build.

### Real gameplay effects

The keystones are connected to runtime mechanics:

- Viper can create persistent venom zones, create a camouflage/critical burst window, or convert poison pressure into healing.
- Python can scale power and shielding from snake length, turn BULWARK into a repeating fortress pulse, or use COIL as heavy arena control.
- Cobra can specialize V into wide barrages, dense armor-piercing artillery, or an element-cycling reaction volley.
- Mamba can turn V into an execution dash, a camouflage/afterimage entry tool, or a hit-to-reset tempo loop.

The regular skills also consume these tree modifiers through their live skill profiles.

## UI changes

The origin is now a small diamond socket with `ORIGIN` and a separate `LV` label rather than a large circular level badge. The tree uses widely spaced ARPG-style socket rails, large angular keystones, class colouring, active-path highlighting, branch labels, and a dedicated doctrine panel.

The tree defaults to a fit-friendly zoom and remains pannable/zoomable with the mouse.
