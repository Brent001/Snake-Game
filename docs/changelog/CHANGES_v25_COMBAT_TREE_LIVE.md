# v25 — Live Combat Tree Integration

- Passive allocations feed live damage, ranged/melee power, crit, HP, regeneration, lifesteal, armor, wall-impact resistance, energy and stamina.
- Active Skill Tree nodes grant an explicit per-skill combat multiplier based on node tier in addition to their authored stats.
- Dash, primary attacks, Coil, Shed, Heat Sense, Scent, Spit, Rattle, Camouflage, Volley, Bulwark and the Signature skill consume their own skill-tree power.
- Allocation/refund produces visible in-game feedback and a persistent BUILD LIVE line.
- Combat HUD shows live DMG, CRIT, LEECH and ENERGY values so the impact is visible outside the tree.
- Skill-node descriptions are shown in a fixed sidebar inspector rather than a mouse-following popup, so text is never hidden behind the node.
