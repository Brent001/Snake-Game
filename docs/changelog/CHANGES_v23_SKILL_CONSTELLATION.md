# v23 — Active Skill Constellation

The active **SKILL TREE** was redesigned separately from the character PASSIVE TREE.

- All 12 hotbar skills remain visible in one overview: SHIFT Dash, LMB Strike, Q Coil, E Shed, R Heat Sense, T Tongue/Scent, Y Spit, F Rattle, G Camouflage, Z Volley, C Bulwark, and V Signature.
- Each skill keeps its functional ROOT -> 3 specialization paths -> MASTERY -> 2 CAPSTONES graph.
- The old 4x3 rectangular card layout was replaced with a 12-branch radial constellation around an **ACTIVE SKILL CORE**.
- Every skill branch is color-coded, with a distinct root, minor nodes, notables, majors, mastery socket, and capstones.
- Cross-links remain functional but are visually quieter until the player hovers a nearby node.
- The central core-to-root spokes make it obvious which skill constellation a cluster belongs to.
- The sidebar is still the complete all-skill index and can be collapsed with the mouse or H.
- The existing mouse cursor behavior, allocation, refunding, zoom and pan interactions are preserved.
